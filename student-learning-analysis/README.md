# Student Learning Analysis

This project analyzes sample student learning data to identify trends in attendance, study time, assessment performance, and final grades.

## Project Structure

- `data/stat1_sample.csv`: Sample dataset for analysis.
- `sql/schema.sql`: Database schema and table definition.
- `sql/analysis.sql`: Core analysis queries.
- `sql/advanced_queries.sql`: Deeper segmentation and ranking queries.
- `insights/findings.md`: Summary of findings and recommendations.
- `visuals/charts.png`: Placeholder chart image.
- `docs/report.pdf`: Placeholder report file.

## Suggested Workflow

1. Load `data/stat1_sample.csv` into a SQL database using the schema in `sql/schema.sql`.
2. Run the queries in `sql/analysis.sql`.
3. Explore additional patterns using `sql/advanced_queries.sql`.
4. Update `insights/findings.md` with your real results.
5. Replace the placeholder chart and report with final deliverables.
